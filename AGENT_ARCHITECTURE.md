# Positron Agent Architecture

CHANNEL / INTERNAL EVENT
→ AUTHENTICATE
→ GATEWAY
→ CONTEXT / MEMORY
→ REASON
→ PLAN
→ SELF-CHALLENGE
→ VALUE/RISK
→ GUARDIAN
→ AUTHORIZE
→ TOOL/SKILL ACTION
→ VERIFY
→ COMMIT
→ JOURNAL / CHECKPOINT
→ REFLECT / SELF-MODEL UPDATE

Scheduled and background tasks enter the same path. They do not receive a privileged execution route.
